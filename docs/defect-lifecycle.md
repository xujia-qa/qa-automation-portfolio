# 缺陷案例：登录失败提示区分账号是否存在

## 一、基本信息

| 项 | 内容 |
|---|---|
| 缺陷编号 | BUG-2026-1127-001 |
| 标题 | 登录失败提示区分"账号不存在"与"密码错误"，存在账号枚举风险 |
| 所属模块 | 用户中心 / 登录 |
| 发现版本 | v1.2.3（测试环境） |
| 环境 | Windows 11 + Chrome；接口 POST /v1/login |
| 严重程度 | 中（信息泄露） |
| 优先级 | 高（安全类，本迭代修复） |
| 提交人 | Xu Jia，2026-11-27 |

## 二、复现步骤

1. 用已注册手机号 + 错误密码调用登录接口
2. 用未注册手机号 + 任意密码调用登录接口
3. 对比两次响应内容

## 三、预期 vs 实际

| | 内容 |
|---|---|
| 预期（依据需求 R8） | 两种失败均返回 code=1001，msg="账号或密码错误" |
| 实际 | 已注册返回"密码错误"；未注册返回"该账号不存在" |

## 四、影响

可批量探测手机号是否注册，为撞库和短信轰炸提供目标
