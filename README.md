# QA Automation Portfolio

软件测试 / 接口自动化学习仓库，记录从零到能独立写接口自动化测试的完整过程。

## 目标

- 掌握测试基础理论（V/W 模型、缺陷生命周期、等价类/边界值）
- 用 Python + requests 完成接口测试
- 用 pytest 组织用例、参数化、生成 HTML 报告
- 产出一个可演示的接口自动化测试项目

## 技术栈

- Python 3.13
- pytest / requests
- Git / GitHub
